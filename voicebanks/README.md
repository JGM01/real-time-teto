# Voicebanks

This directory is for user-supplied UTAU voicebanks. The repository does not
distribute them.

## Teto English CVVC

Download the official archive from:

https://kasaneteto.jp/assets/download/utau/TETO-English-150401.zip

The expected SHA-256 is in `teto-speech/assets/p3-sources.json`.

Place the archive at `voicebanks/TETO-English-150401.zip`. The importer reads
the archive from an explicit local path. The archive stays out of version control.

The Teto voicebank is not open source. Its own terms apply. The code in this
repository is MIT OR Apache-2.0; that license does not cover the recordings.
